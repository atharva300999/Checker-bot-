## 🎯 About

This Telegram bot allows you to check bulk Crunchyroll accounts (email:password combos) and detect which ones have **active premium subscriptions**. The bot features a user-friendly interface with **only buttons** (no commands), real-time progress tracking, CSV export, proxy support, and a complete admin panel.

### Why This Bot?

- 🔐 **No API registration needed** - Uses public Crunchyroll credentials
- 🚀 **Fast multi-threaded checking** - Check thousands of accounts quickly
- 👑 **Complete admin control** - Manage users, proxies, and broadcasts
- 📊 **Detailed results** - Shows subscription plans, renewal dates, and countries
- 💾 **CSV export** - Download valid accounts with all details

## ✨ Features

### For Users
| Feature | Description |
|---------|-------------|
| 🍣 **Crunchyroll Checking** | Upload combo files and get premium accounts |
| 📊 **Personal Statistics** | Track your total checks and hit rate |
| 📜 **Check History** | View your last 10 checks |
| 📧 **Hotmail Checker** | Coming soon (button ready) |
| ❓ **Help & Support** | Built-in help system |

### For Admins
| Feature | Description |
|---------|-------------|
| 📊 **Bot Statistics** | View total users, checks, hits, and hit rate |
| 👥 **User Management** | View all users, ban/unban anyone |
| 📢 **Broadcast System** | Send messages to all users |
| 🔌 **Proxy Management** | Add, list, and delete proxies |
| ⚙️ **Full Control** | Complete bot management from Telegram |

### Technical Features
- 🔐 **No API keys needed** - Public Crunchyroll credentials work out of the box
- 🌐 **Proxy rotation** - Use proxies to avoid rate limiting
- 📊 **Real-time progress** - Live progress bar during checks
- 💾 **SQLite database** - Persistent storage for users and logs
- 🚀 **Multi-threaded** - Fast checking with configurable threads
- 📁 **CSV export** - Download results in CSV format
- 🔄 **Auto-retry** - Automatic retry on failures
- 🛡️ **Rate limit handling** - Smart handling of API limits
